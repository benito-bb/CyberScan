# CyberScan
Projet personnel en cybersécurité sur une application d'analyse de sécurité logicielle.

Elle centralisera les resultats de différents outils de sécurité afin détecter les vulnérabilités dans le code python, de secrets exposés et de dépendances vulnérables.

## Objectifs
Analyser statiquement du code Python.
Détecter des secrets potentiellement exposés.
Auditer les dépendances Python.
Normaliser et classer les alertes de sécurité.
Générer des rapports d'analyse.
Intégrer des contrôles de automatisés.

## Technologies prévues
Python
FastAPI
React
TypeScript
SQLite
Bandit
Gitleaks
pip-audit

GitHub Actions

## État du projet
Actuellement en phase de démarrage.

Les fonctionnalités seront documentées au fur et à mesure de leur implémentation et de leur validation oar des tests.

## Utilisation responsable
CyberScan est destiné à l'analyse de projets que l'utilisateur possède ou qu'il est explicitement autorisé à examiner.

On utilisera des environnements de test contrôlés et des exemples synthétiques pour vérifier le fonctionnement de ses outils de sécurité.
